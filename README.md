# RSHQ — Static Website

A fast, responsive static website for RSHQ, focused on mindset, habit building, human behaviour and life coaching.

## Files

- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — small footer year script

## Before publishing

Open `index.html` and replace:

1. `https://YOUR-BOOKING-LINK.example` with your actual booking page.
2. `mailto:YOUR-EMAIL@example.com` with your email address.

You can later add links to your preferred booking/payment platforms without changing the website structure.

## Deploy with GitHub Pages

1. Create/open your GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Commit and push.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save.
8. GitHub will give you a `github.io` URL.

## Connect rshq.com

At your domain provider, point the domain to GitHub Pages using the DNS records GitHub currently provides for your repository.

GitHub's recommended DNS records can change, so use the current instructions shown in your repository's **Settings → Pages** screen rather than copying old DNS values from a tutorial.

Then add `rshq.com` as the **Custom domain** in GitHub Pages.
